# 《明日方舟》「月行水上」 开场动画复刻

使用 HTML、JavaScript 和 CSS 在浏览器中复刻《明日方舟》ACT54SIDE 的开场动画。项目基于 Unity AssetBundle 解包得到的场景、贴图与动画曲线，并结合原版录屏校准布局、遮罩和图层效果，无需 Unity 或前端构建工具。

## 功能

- 逻辑分辨率为 **1920×1080**，按 **60 Hz** 求值 436 条动画曲线；动画时长 6.5 秒，共 390 帧时间轴。
- 支持播放、暂停、重播、逐帧查看和拖动时间轴。
- 自适应可视区域：竖屏顺时针旋转 90°，以 9:16 显示；横屏恢复 16:9，切换不重置进度。
- 音效与背景音乐独立调度，允许重叠播放；动画结束后，音频继续播放完。
- 首次进入默认静音，不加载音频；点击“解除静音”后加载并记住偏好。刷新若被浏览器阻止有声自动播放，可再次点击恢复。
- 时间轴与静音按钮首次进入页面时默认隐藏，移动鼠标、点击页面或键盘操作时恢复；3 秒无操作后同步隐藏，拖动与长按期间保持显示。

## 本地运行

在项目根目录启动静态 HTTP 服务，例如使用 Python 3：

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4174/>。页面默认自动播放动画。

请通过 HTTP 服务访问，不要直接双击 `index.html`：项目使用 ES Modules，并通过 `fetch` 加载音频。

可选 URL 参数：

- `?autoplay=0`：载入后暂停在起始帧，便于调试。
- `?loop=1`：循环播放动画，每轮重新调度音频。
- `?autoplay=0&loop=1`：结合以上两种设置。

## 操作与配置

空格切换播放/暂停，`R` 重播，`←` / `→` 调整一帧，`H` 切换控制栏显示。触屏设备可直接使用按钮和时间轴。

在 `audio-timeline.js` 顶部调整两条音轨相对于动画起点的起播时间，单位为秒：

```javascript
export const LOAD_SOUND_START_SECONDS = 0.5;
export const INTRO_MUSIC_START_SECONDS = 1;
```

暂停、拖动和重播会同步控制音频；播放途中解除静音会从当前时间轴对应的音频位置开始，不会从头补播。

控制栏自动隐藏延时由 `app.js` 中的 `CONTROLS_IDLE_DELAY_MS` 配置，单位为毫秒，默认 `3000`。

## 目录结构

```text
.
├── assets/
│   ├── audio/           # 开场音效与背景音乐
│   └── images/          # 动画贴图与遮罩图片
├── index.html           # 页面入口与控制栏
├── styles.css           # 画面、响应式布局与交互样式
├── app.js               # 场景布局、图层合成与播放控制
├── scene-data.js        # 场景层级、贴图引用与动画曲线数据
├── curve-runtime.js     # 曲线插值与旋转计算
├── audio-timeline.js    # 音轨配置、加载与时间轴调度
└── README.md
```

图片保留解包时的原始文件名，便于对应场景数据；静态素材均放在 `assets/` 下。
